# GHOSTCLUB 5.0 – Virtual Club World (Unity & Blender)

Inspiriert von **0b4k3's GHOSTCLUB 5.0** (VRChat / CGWORLD JAM ONLINE 2022):
* Monumentale brutalistische Architektur aus Sichtbeton mit monolithischen Pfeilern
* Abgesenkte, reflektierende Tanzfläche mit umlaufenden Betontreppen
* Monumentaler DJ-Altar mit Lautsprechertürmen und gigantischem vertikalem VJ-Monolithen
* Schwebende Lichttraversen mit Moving-Heads, Laser-Arrays und Stroboskop-Effekten
* Prozedurale Echtzeit-Glitch-Visuals und 132 BPM Sub-Bass/Techno-Klangsynthese

---

## 1-Klick Szenen-Erstellung in Unity

1. Wechsle in das geöffnete Unity-Editor-Fenster (damit Unity die neuen Assets kompiliert).
2. Klicke in der oberen Menüleiste auf:
   **Ghostclub → Build Ghostclub 5.0 Scene**
3. Die Szene wird komplett zusammengesetzt und unter `Assets/GhostclubWorld/Scenes/Ghostclub_5_0.unity` gespeichert:
   * 3D-Geometrie mit MeshCollidern auf allen Böden, Treppen und Wänden
   * Vollständiges Club-Licht-Rig (Moving-Heads, Laser, Strobes)
   * URP Post-Processing Global Volume (Bloom, ACES Tonemapping, Vignette, Fog)
   * VJ-Monolith mit prozeduraler Glitch-Animation
   * First-Person-Player auf der erhöhten Galerie inklusive Audio-Rumble
4. Drücke **Play (▶)** in Unity:
   * **W, A, S, D:** Bewegen
   * **Maus:** Umschauen
   * **Shift:** Sprinten
   * **Leertaste:** Springen
   * **Escape:** Mauszeiger freigeben / fangen
